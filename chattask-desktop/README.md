# ChatTask Desktop

既存のバニラJavaScript版をReact + TypeScript + Tauriへ移植したデスクトップ版です。

Windows での初回セットアップと起動、インストーラー作成は [Windows向け手順](../docs/windows-setup.md) を参照してください。

## 開発（macOS）

```bash
source "$HOME/.cargo/env"
npm install
npm run tauri dev
```

## ビルド（macOS）

```bash
npm run build
npm run tauri build -- --bundles app
```

## 今日の着手順をAIに相談する

「今日」の「AIに着手順を相談」から、普段使っているAIチャットにコピーするプロンプトを作成できます。
画面は「相談」「JSON作成」「取り込み・確認」の3つのタブに分かれています。切り替えても入力内容を保持し、閉じて開き直した場合も最後に開いたタブから再開できます。

1. 今日この後に使える時間（任意）と、タスクごとの補足情報を入力します。同じタスクの複数作業は一つの補足を共有し、入力欄には対象の作業名も表示します。相手との約束・先に必要な確認などは各タスクへ、動かせない予定・集中力など共通の条件は「全体の補足（任意）」へ入力できます。従来の補足は全体の補足として保持します。
2. 「相談用プロンプトをコピー」を押し、AIチャットで質問へ答えながら着手順を相談します。同じ相手への確認など、まとめる効果がある作業はグループ化も提案してもらえます。順番・グループ名・対象・理由を確認し、合意します。
3. 「JSON作成」タブの「ファイル作成用プロンプトをコピー」を押し、相談していた同じAIチャットの最後へ貼り付けます。会話で最後に合意した内容だけをJSONファイルにします。サマリーをアプリへ貼り戻す必要はありません。相談履歴や合意がない場合、未確定事項が残っている場合は、AIに確認を続けるよう指示しています。
4. JSONファイルを選ぶか内容を貼り付け、「内容を確認」で名称・変更後の順番・理由・最初の一歩を確認します。グループ化がある場合は「新しくまとめるグループ」の名称・対象・理由も確認し、「グループ化と対応順を反映」を押します。グループ化がない場合は「この対応順を反映」です。

対象は現在の対応順にある作業です。一時待ち・順番未設定の作業を含めたい場合は、先に対応順へ戻してください。新規グループは元の項目2件以上から作成します。既存グループを他の項目とまとめる場合は内部の順番を保ったまま一階層へ統合し、入れ子にはしません。統合しないグループは維持します。「後回し」は対応順の末尾へ回す意味で、別日への移動や削除は行いません。

相談データには、作業固有の説明・日別メモに加え、関連するTaskの説明・次のアクション・期限・優先度・進捗・待ち情報・上位Task・関連Taskの情報も含めます。同じTaskに複数の作業があってもTask情報は一度だけ出力し、作業の `taskId` で関連付けます。Task全体と作業ごとの工数は二重計上しないようプロンプトに明記しています。「相談する予定」内の「AIに渡すTask情報」から内容を確認できます。

タスクごとの補足は `taskSupplements` としてTask ID・名称に紐づけて両プロンプトに含めます。空欄や対応順にないタスクの補足はAIへ渡しません。補足はこの日のAI相談用で、登録済みのTask説明や作業メモを変更しません。タスク別補足を変更した場合も古いJSONは無効になり、最新の相談用プロンプトから相談し直します。

新しいファイル作成用プロンプトはグループ提案に対応した `schemaVersion: 2` を生成します。グループ化がない場合の `groups` は空配列です。以前の `schemaVersion: 1` の並べ替え用JSONも取り込めます。

取り込みでは日付・相談内容の識別子・全項目のIDを検証し、別の日、重複、不足、未知の項目、未確定事項がある提案を拒否します。相談後に予定・対応順・グループやアプリ側の補足・利用可能時間を変更した場合は、最新の相談用プロンプトで相談し直し、JSONを作り直してください。AIとの会話内で更新した条件は、初期の補足情報より優先して出力するよう指示しています。アプリからAIの会話履歴は参照できないため、取り込み前のプレビューで実際の合意内容と一致していることを確認してください。

補足情報・JSONの入力は日付別・本番／テスト環境別にこの端末へ保存します。AIへの直接通信は行わず、コピーした情報をどのAIへ渡すかは利用者が選びます。

## ソース構成

```text
src/
├── components/
│   ├── Header.tsx              ヘッダーと入出力操作
│   ├── Sidebar.tsx             検索・フィルター・タスク一覧
│   ├── TaskCard.tsx            タスクカード
│   ├── TaskDetail.tsx          タスク詳細・日別計画・メモ
│   ├── TodayModal.tsx          今日のページ
│   ├── DocumentsModal.tsx      タスクドキュメント
│   ├── TagSettingsModal.tsx    タグ設定
│   └── Modal.tsx               共通モーダル
├── data/constants.ts           ステータス・優先度などの定義
├── services/storage.ts         保存・旧データ正規化・JSON移行
├── types.ts                    データ型
├── utils.ts                    日付・URL・予定期間処理
├── App.tsx                     アプリ状態と画面の接続
└── App.css                     共通スタイル
```

## Web版からのデータ移行

1. Web版の設定から「データをエクスポート」を実行します。
2. デスクトップ版の「読み込み」からJSONファイルを選択します。
3. タスク、タグ、履歴、日別メモ、休暇データが読み込まれます。

デスクトップ版ではSQLiteへ保存し、初回起動時に従来のlocalStorageデータを移行します。ブラウザ互換モードではlocalStorageを使用します。

## 移植済み機能

- タスク、親子タスク、ステータス、優先度、案件タグ
- 検索、一覧フィルター、カード密度・一覧幅・折りたたみ
- 複数予定日・予定期間、日別計画、達成チェック、持ち越し
- 定期タスク、各回の実施・スキップ・別日移動・移動理由
- 今日のページ、日次メモ、休暇・祝日・土日判定
- 関連リンク、Markdownメモ、変更履歴
- 複数ドキュメントとNotion風ブロックエディター
- ガントチャート、日次・週次・月次・任意期間のMarkdownまとめ
- ヘルプ、設定状態の保存、Web版JSONの読み込み・書き出し

SQLite、添付ファイル、ユーザープロフィール、完全バックアップは、デスクトップ版固有の機能として実装されています。完全バックアップには添付ファイルとChatTask管理下のローカルツールも含まれます。

移植対象と実装状況は [MIGRATION_CHECKLIST.md](./MIGRATION_CHECKLIST.md) を参照してください。
# テスト

プロジェクト連携や工数集計など、データを書き換える処理の回帰テストにはVitestを使用します。

```bash
npm test
```

開発中にファイル変更を監視して再実行する場合は、次を使用します。

```bash
npm run test:watch
```

テストと本番ビルドをまとめて確認する場合は、次を使用します。GitHub Actionsでも同じ確認を自動実行します。

```bash
npm run check
```
