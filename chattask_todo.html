ChatTask ヘルプ

項目を選ぶと詳しい使い方を確認できます。

まず始めに
  1. 「新規タスク追加」でタスクを作成します。
  2. ステータス・優先度・案件タグを設定します。
  3. 「やる日」に単日または期間を追加します。
  4. 必要に応じて説明、関連リンク、日付ごとの対応内容を入力します。

「未完了」は完了以外、「進行中」は進行中・定期・待機、「すべて」は完了を含む全タスクを表示します。

今日のページと持ち越し

今日のページでは、指定日の予定・待ち・期限・定期タスク・完了内容をまとめて確認できます。

「持ち越す」を押すと、表示日に予定された未完了タスクを翌日へ追加します。元の日付は履歴として残ります。

日付ごとの対応内容には、達成チェックを付けられます。

親タスクと子タスク

タスク詳細の「親タスク」から関係を設定できます。親タスクの一覧には「完了数 / 総数」が表示されます。

子タスクは親タスクの直下に表示され、親タスクのボタンから折りたためます。

ステータスと定期タスク

ステータスは未着手・進行中・待機・完了のカテゴリに分かれています。「待ち」は申請待ちや回答待ちに利用できます。

定期タスクはマスターを完了にせず、今日のページで各回を「実施済み」「スキップ」「別日に移動」として記録します。

通常の一覧から隠したい場合は、設定の「定期タスクを一覧で非表示」を利用します。今日のページの定期タスクは引き続き表示されます。

休暇・土日・祝日

土曜日と日曜日は自動的に休暇扱いになります。有給は「休暇設定」から単日または期間で登録します。

日本の祝日は、年を指定して取り込めます。再取り込み時の重複日はスキップされます。

休暇日は持ち越し判定、今日のページ、まとめ出力、ガントチャートへ反映されます。

案件タグとガントチャート

案件タグは設定画面で追加・名称変更・並び替え・表示切り替えができます。

ガントチャートでは予定期間、親子関係、優先度、休暇日を確認できます。タグでの絞り込みや日・週・月表示にも対応しています。

ガント上のタスク名を選ぶと詳細画面を開きます。日程変更はタスク詳細から行います。

メモ・リンク・まとめ出力

作業ログは改行できます。記録は Command + Enter（Windowsでは Ctrl + Enter）です。

関連リンクは複数登録でき、クリックすると別タブで開きます。

タスクごとの「ドキュメント」では、チェックリストや長めのメモを複数の文書に分けて管理できます。

「まとめ出力」から日次・週次・月次・任意期間のMarkdownファイルを作成できます。

データの保存

データはこのブラウザ内に保存されます。別のブラウザや端末には自動同期されません。

定期的に「エクスポート」でバックアップし、復元するときは「インポート」を利用してください。

ガントチャート

予定期間を閲覧できます。タスクを選ぶと詳細を開きます。
