設定を変更するとコマンドがリアルタイムに更新されます
$ git --no-pager diff main...HEAD | pbcopy

Macの場合、末尾に | pbcopy を付けて実行すると、結果が直接クリップボードに格納されます。

PHP を使ってブラウザからボタン1つで自動実行する

Laravel（PHP）を開発されているため、Macのターミナルで php -v を打つとPHPが既に利用できます。

プロジェクトフォルダ内に diff_server.php を1つ置くだけで、ブラウザからボタン1つで即実行できるようになります：

# ターミナルで起動するコマンド:
$ php -S 127.0.0.1:8000

※ ご希望の場合は、PHP 組み込みサーバー用のコード（1ファイル完結型）もいつでもご提供できますのでお申し付けください。
